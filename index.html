Making Your First Commit

Add Git tracking to a folder

It will create a hidden .git folder

					
						$ git init
Remember .git is a HIDDEN FOLDER. Some people won't see it.

Making Your First Commit

Stage your changes

These are the file changes you plan to commit

					
						$ git add .
Explain this is like being at the checkout line with your items.

Making Your First Commit

Set your username and email

Every commit you make will have an author

					
						$ git config --global user.email "you@example.com"
						$ git config --global user.name "Your Name"
						# You can check with:
						$ git config get user.name
						$ git config get user.email
If staging is a checkout line, commits are when you checkout. This is now a save point in your projects history.

Making Your First Commit

Now Commit!

This is now a snapshot you can always look back at

					
						$ git commit -m "My first commit"

Making Your Second Commit

Use what you've learned and commit a new change

					
						$ git add .
						$ git commit -m "Add more exclamations"

Merging A Branch

Create a new branch, switch to it, and commit a change

					
						$ git switch -c new-logo # -c creates the branch
						$ git add .
						$ git commit -m "Replace old logo"

Merging A Branch

Switch back to main and merge the other branch 

					
						$ git switch main
						$ git merge new-logo
